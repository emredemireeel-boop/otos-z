# Inter local font

Source: https://github.com/rsms/inter/blob/master/docs/font-files/InterVariable.woff2
License: SIL Open Font License 1.1, preserved in `Inter-OFL.txt`.

Downloaded 2026-10-29 from the Inter project's repository. `InterLatinTR.woff2` is a subset for Latin/Turkish content and punctuation, retaining the variable weight axis (100–900). The optical-size axis was instantiated at its default value 14. Missing characters use the declared system fallback.

Prepared with fontTools 4.63.0: subset U+0000–017F, U+2000–206F and U+20AC, retain layout features, WOFF2 output. The resulting asset is 70,312 bytes. `next/font/local` serves it from the site's own origin with display swap and adjusted fallback metrics. No external Google Fonts stylesheet or browser request is required.
