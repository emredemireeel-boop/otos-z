## Yayın kontrolü

`deploy/release.sh`, ayrı bir candidate klasöründe tip üretimi, `tsc`, production build ve `npm run seo:check` çalıştırır. Hata varsa PM2 yeniden başlatılmaz. Hazırlama modu, bütün kontroller geçse bile etkinleştirmeden çıkar. Yalnız test edilmiş candidate seçilerek mevcut `otosoz` uygulaması yeniden başlatılır; eski build geri dönüş için korunur. Yayından sonra aynı kontroller kamuya açık Cloudflare yanıtlarına uygulanır.

Forum CSS kapsamındaki hata için denenen eski build'e dönüş sırasında HTTP 500 yanıtları görüldü. Çalışan build'e dönülüp kapsam/keyframe hatası düzeltildi; son aday ayrı sunucuda yeniden doğrulandı. Kesintinin kesin süresi belirlenemedi. Olay ve ara başarısız tarama `deployment-20261029/incident-and-recovery.json` dosyasında korunur. Gelecek yayında çalışan `node_modules` klasörünün değiştirilmesi engellenir; eski build yalnız `BUILD_ID` var diye geri dönüşe uygun sayılmaz.

- `http://www.otosoz.com/` adresi iki 301 ile HTTPS apex'e ulaşıyor. İç link ve sitemap denetimlerinde yönlendirme 0; alan adının bu dış varyantı ayrı tutulur. Cloud project `244436311966` API-disabled HTTP 403 döndürdüğünden metrikler ve 50 URL'nin indeks durumları alınamadı; bunlar sıfır trafik veya geçerli indeks durumu gibi gösterilmez. API açılınca script tekrar çalıştırılmalıdır.
